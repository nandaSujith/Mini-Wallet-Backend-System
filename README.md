# Mini Wallet Backend System

## Project Overview

Mini Wallet Backend System is developed using ASP.NET Core Web API, C#, Entity Framework Core and SQL Server.

Features

• Register User
• Login
• Wallet Balance
• Credit Wallet
• Debit Wallet
• Wallet to Wallet Transfer
• Transaction History
